
# CS 360 Mobile Architecture and Programming

## Event-Tracking App — Project Three

**Agnes Malum**

### Project Overview

For this project, I developed an Event-Tracking App using Android Studio and Java. The goal was to create a mobile application that allows users to organize and manage important events. The application includes account creation, login functionality, and an SQLite database for storing user information and event details. Users can add events, view upcoming events, and delete events they no longer need. I designed the application for students, working professionals, parents, and anyone who needs a simple way to keep track of activities.

### User Interface Design

My application required two main screens: a login screen and an event-management screen. The login screen allows users to create an account or sign in, while the event-management screen displays upcoming events and provides options to add or delete them. I focused on keeping the layout simple and organized so users could easily understand how to navigate the application. I wanted the features to be accessible without overwhelming users with unnecessary information.

### Coding and Development Approach

I approached the development process by working on different components of the application step by step. I used XML to create the layouts, Java to implement the application functionality, and SQLite to manage the database. I also learned the importance of connecting the user interface to the application logic and testing features as I developed them. In future projects, I plan to continue breaking larger tasks into smaller steps and spending more time planning before coding.

### Testing and Functionality

I tested the application using the Android Studio emulator. I verified that users could create accounts, log in, add events, view stored events, and delete events. I also tested the SMS permission request and confirmed that the application continued functioning when permission was denied. Testing was important because it helped me identify problems that were not obvious from looking at the code alone.

### Challenges and Problem-Solving

One of my biggest challenges occurred when the application closed unexpectedly after a successful login. After investigating the error, I discovered that the SQLite database needed to be updated to include the events table. I resolved the problem by updating the database version and testing the application again. This experience taught me the importance of debugging, understanding error messages, and checking how different parts of an application interact.

### My Most Successful Component

I believe the database functionality was one of my biggest accomplishments in this project. Although I experienced challenges while developing it, I successfully connected the SQLite database to the application's interface. Users could add events, see them displayed on the screen, and delete them when necessary. Seeing these features work together helped me understand how data storage and user interaction are connected in mobile application development.

### Reflection

Completing this project helped me gain practical experience with Android Studio, Java, XML layouts, SQLite, and mobile application testing. Before taking this course, I did not fully understand how much planning, testing, and troubleshooting were involved in developing an application. I now have a better understanding of the development process and how important user-centered design is. I plan to continue improving my skills and use this project as part of my professional portfolio.
